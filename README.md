# Clikto — Sites Artisans Plombiers

50 sites vitrines personnalisés pour artisans plombiers, générés automatiquement.

## Activation GitHub Pages

1. Va dans **Settings** > **Pages**
2. Source : **Deploy from a branch**
3. Branch : **main** / **(root)**
4. Clique **Save**
5. Attends 2-3 minutes, tes sites seront en ligne !

## URLs

Chaque site sera accessible à :
`https://TON-PSEUDO.github.io/clikto-sites/NOM-DU-FICHIER.html`

L'index complet est à :
`https://TON-PSEUDO.github.io/clikto-sites/`
